# CHANAKYA AI v5.0 — Professional Trading Platform

## TECH STACK
- Backend: Python Flask
- Auth: Firebase Gmail login
- DB: Firebase Firestore + SQLite local
- Cache: File-based cache (no Redis needed)
- AI: Groq LLaMA 3.3 70B + XGBoost
- Broker: Angel One SmartAPI
- Real-time: SSE (Server-Sent Events)
- Frontend: Single HTML file (SPA)
- Port: 5002
- URL: bramha.cloud/v5

## SUBSCRIPTION TIERS
- developer: No expiry, ALL features
- administrator: No expiry, ALL features
- platinum: 365 days, all features
- gold: 180 days, live trading
- silver: 90 days, paper only
- premium: 30 days, basic
- demo: 15 days, paper + global broker

## KEY PRINCIPLES
1. Global broker always connected (24x7)
2. One data fetch → cached → all engines use
3. Paper and Live completely separate
4. No duplicate API calls
5. Rate limit safe
6. Crash proof — try/except everywhere
